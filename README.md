One dad joke, told out loud: the fog that mists the moment. A father tells his kids the fog never stays for dinner — it just mists the moment, then it's gone. One phonetic turn, punchline at the end, no recycled classic.

## Run it

```sh
python3 main.py
```

Writes the joke to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output/entry.txt`): exactly 88 characters, UTF-8, no trailing newline. Standard library only, deterministic — the same bytes on every run.
